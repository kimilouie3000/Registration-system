# Registration System

A simple PHP and MySQL user registration system with CRUD operations, search, login, and profile picture upload.

## Features

- Add users
- View users
- Edit users
- Delete users
- Search users
- User login and logout
- Password hashing
- Profile picture upload

## Technologies

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Setup

1. Put the project in `C:\xampp\htdocs\registration-system`
2. Start Apache and MySQL in XAMPP.
3. Create the `registration_db` database in phpMyAdmin.
4. Open the project at:

`http://localhost/registration-system/`
